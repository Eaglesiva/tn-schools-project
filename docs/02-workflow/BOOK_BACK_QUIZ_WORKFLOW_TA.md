# Book Back Questions & Quiz Workflow — Common Rules (Classes 1–12)

> **ஆவணத்தின் நோக்கம்:** Class 1–12, எல்லா பாடங்கள் / மொழிகள் / Medium-களிலும் Book Back கேள்விகளுக்கான பணியை ஒரே தெளிவான வரிசையில் செய்வது.
> **முக்கியம்:** இந்த ஆவணத்தில்தான் Step 1 → Step 2 → Step 3 என்ற கட்டாய செயல்வரிசை வரையறுக்கப்படுகிறது. ஒவ்வொரு Subject-இன் folder-லும் இதே வரிசையைப் பின்பற்ற வேண்டும்.

## தொடங்குவதற்கு முன் — Edition Gate

1. முதலில் அந்த Class + Subject + Medium + Term / Annual + Volume-க்கான புத்தகத்தை அடையாளம் காண்க.
2. `docs/BOOK_EDITION_VERIFICATION_RULES_TA.md`-ஐப் பின்பற்றி official listing / PDF / imprint / TOC / Book Back pages கிடைக்கும் ஆதாரங்களால் பதிப்பைச் சரிபார்க்கவும்.
3. Edition உறுதியாகாத நிலையில் இறுதி Answers / Quiz publish செய்ய வேண்டாம்; நிலையைத் தெளிவாக `CURRENT_VALIDITY_UNVERIFIED` அல்லது பொருத்தமான status-ஆகப் பதிவு செய்து blocker-ஐக் குறிப்பிடவும்.
4. Edition Gate முடிந்ததும் கீழே உள்ள 3 Steps-ஐ வரிசையாகச் செய்யவும்.

---

## STEP 1 — `answers.md`: கேள்வி பட்டியல் + விடை ஆதாரம்

**முதலில் செய்ய வேண்டியது இதுதான்.**

### செய்ய வேண்டியவை
1. அந்த Unit / Lesson-இன் `questions.md`-ஐ முழுமையாகப் படிக்கவும்.
2. பாடநூல் PDF-இல் அதே Book Back / Evaluation பக்கங்களைத் திறந்து, கேள்வி wording, section, numbering, வரிசை ஆகியவற்றை ஒப்பிடவும்.
3. `answers.md` உருவாக்கும்போது அல்லது புதுப்பிக்கும்போது, `questions.md`-ல் உள்ள எல்லா வினாக்களும் அதே வரிசையில் இடம்பெற வேண்டும். கேள்வியைச் சுருக்கவோ, மறுவரிசைப்படுத்தவோ, தவறவிடவோ கூடாது.
4. One-mark / One-word / Objective வினாக்களுக்கு சரியான விடை, சுருக்கமான விளக்கம், திறந்து பார்த்த Direct Source URL மற்றும் தேவையான PDF page reference சேர்க்கவும்.
5. விடை உறுதியாகாத வினாக்களுக்கு ஊகித்து எழுத வேண்டாம்; `ANSWER_NOT_FOUND` அல்லது `REVIEW_REQUIRED` எனக் குறிக்கவும்.
6. குறு / சிறு / நெடு / விரிவான வினாக்களுக்கு ஏற்கெனவே உள்ள placeholder அமைப்பை மட்டும் பாதுகாக்கவும்: `விடைக்குறிப்பு`, `சாதாரண விடை`, `விரிவான விடை`. Answer content உருவாக்க வேண்டாம்; அந்த scope-க்கு உரிய Source links இருந்தால் பாதுகாக்கவும்.
7. படம் / வரைபடம் / அட்டவணை தேவைப்படும் வினாக்களை source page-ஐத் திறந்து பார்த்த பிறகே வகைப்படுத்தவும்.

### STEP 1 முடிந்ததாகக் கருத வேண்டிய நிபந்தனைகள்
- [ ] `questions.md`-ல் உள்ள எல்லா வினாக்களும் `answers.md`-ல் உள்ளன.
- [ ] வினாக்களின் wording, section, numbering, order மாற்றமின்றி உள்ளன.
- [ ] ஒவ்வொரு Answer-bearing one-mark பதிவுக்கும் விடை + விளக்கம் + Direct Source + verification status உள்ளது.
- [ ] பெரிய வினாக்கள் placeholder வடிவில் உள்ளன; முழு விடைகள் எழுதப்படவில்லை.
- [ ] காணாமல் போன / படத்தை சார்ந்த / ஆதாரம் இல்லாத பதிவுகள் வெளிப்படையாகக் குறிக்கப்பட்டுள்ளன.

**STEP 1 முடிந்த பிறகே STEP 2 தொடங்க வேண்டும்.**

---

## STEP 2 — `quiz.md`: பாடநூல் அசல் Objective வினாக்கள்

**இரண்டாவதாகச் செய்ய வேண்டியது இதுதான்.**

### செய்ய வேண்டியவை
1. STEP 1-இல் சரிபார்க்கப்பட்ட கேள்விப் பட்டியலிலிருந்து பாடநூலிலேயே நான்கு options-உடன் உள்ள அசல் MCQ / Objective வினாக்களைத் தேர்ந்தெடுக்கவும்.
2. கேள்வி wording, A/B/C/D option wording, original answer மற்றும் option order ஆகியவற்றை பாடநூலுடன் ஒப்பிட்டு அப்படியே பாதுகாக்கவும்.
3. பாடநூலில் நான்கு options இல்லாத கேள்வியை அசல் MCQ என்று காட்டக்கூடாது; அத்தகைய மாற்றம் STEP 3-ல் மட்டுமே செய்யப்படும்.
4. ஒவ்வொரு பதிவு `quiz.md`-ல் வாசிக்க எளிய ஒரே வடிவில் இருக்க வேண்டும்: கேள்வி, நான்கு options, சரியான விடை, சுருக்கமான விளக்கம், Source.
5. Original textbook options-ஐ மறைமுகமாக மாற்றவோ, புதிய distractor-களை textbook options எனக் காட்டவோ கூடாது.

### STEP 2 முடிந்ததாகக் கருத வேண்டிய நிபந்தனைகள்
- [ ] பாடநூலில் உள்ள அனைத்து தகுதியான original four-option MCQ-களும் சேர்க்கப்பட்டுள்ளன.
- [ ] கேள்வி மற்றும் நான்கு options அசல் புத்தகத்துடன் பொருந்துகின்றன.
- [ ] Answer key / option order சரிபார்க்கப்பட்டுள்ளது.
- [ ] STEP 3 மூலம் மாற்றப்படும் கேள்விகள் original MCQ-களிலிருந்து தெளிவாக வேறுபடுத்தப்பட்டுள்ளன.

**STEP 2 முடிந்த பிறகே STEP 3 தொடங்க வேண்டும்.**

---

## STEP 3 — `quiz.md` + `quiz.json`: மாற்றக்கூடிய மற்ற One-mark வினாக்கள்

**மூன்றாவதாகச் செய்ய வேண்டியது இதுதான்.**

### Quiz-ஆக மாற்றத் தகுதியானவை
STEP 1-ல் வகைப்படுத்திய மற்ற ஒரு மதிப்பெண் / ஒருசொல் / குறுகிய objective வினாக்களை, ஒரே ஒரு விடை தெளிவாக உறுதிப்படுத்தப்பட்டால், நான்கு options கொண்ட MCQ-ஆக மாற்றவும். எடுத்துக்காட்டாக:
- கோடிட்ட இடம் நிரப்புக.
- ஒரு சொல் / ஒரு வரி விடை.
- பொருத்துக.
- சரியான இணை / தவறான இணை கண்டறிதல்.
- கட்ட / குறுக்கெழுத்து / grid clue — எழுத்து அல்லது clue முழுமையாகக் கிடைத்தால்.
- பொருள், இலக்கணம், பெயர், ஆண்டு, எண் போன்ற ஒரே விடை கொண்ட வினாக்கள்.

### மாற்றக்கூடாதவை
- குறுவினா, சிறுவினா, நெடுவினா, கட்டுரை, விரிவான விளக்கவுரை.
- பல சாத்தியமான பதில்கள் உள்ள திறந்தநிலை / படைப்பாற்றல் வினாக்கள்.
- பதில் உறுதிப்படுத்தப்படாத கேள்விகள்.
- தேவையான படம் / வரைபடம் / அட்டவணை கிடைக்காததால் கேள்வியைப் புரிந்துகொள்ள முடியாத image-dependent வினாக்கள். இவற்றை `answers.md`-ல் வைத்திருக்கவும்; Quiz-க்கு சேர்க்க வேண்டாம்.

### Distractor விதிகள்
1. ஒவ்வொரு transformed item-க்கும் துல்லியமாக நான்கு தனித்தனி options (A, B, C, D) உருவாக்கவும்.
2. ஒரே ஒரு சரியான விடை மட்டுமே இருக்க வேண்டும்.
3. Distractors பொருத்தமானவை, ஆனால் தவறானவை என்பதை source / பாடநூல் context-உடன் உறுதிப்படுத்தவும்.
4. அசல் கேள்வியின் பொருள் அல்லது சுட்டும் context மாற்றப்படக்கூடாது.
5. Generated distractors என்பது உருவாக்கப்பட்டவை; அவற்றை அசல் பாடநூல் options என்று சொல்லக்கூடாது.
6. Option order மாறினால் correct answer index-ஐ மீண்டும் சரிபார்க்கவும்.

### கோப்புகள் ஒத்திசைவு
- `quiz.md` — original MCQ + transformed eligible one-mark MCQ அனைத்தும் இடம்பெற வேண்டும்.
- `quiz.json` — `quiz.md`-இன் அதே பதிவுகள், அதே order, அதே options, answer, explanation மற்றும் source metadata கொண்டிருக்க வேண்டும்.
- Unit / Lesson JSON-களை subject-level Master Quiz-இல் repository convention-க்கு ஏற்ப sync செய்யவும்.
- Image-dependent / long-answer / unresolved items Quiz JSON-ல் இருக்கக்கூடாது.

### STEP 3 முடிந்ததாகக் கருத வேண்டிய நிபந்தனைகள்
- [ ] மாற்றத்தகுதியான எல்லா one-mark items-மும் சேர்க்கப்பட்டுள்ளன.
- [ ] பொருத்துக / fill-in / one-word / grid போன்ற item வகைகள் பரிசீலிக்கப்பட்டுள்ளன.
- [ ] image-dependent source இல்லாத வினாக்கள் தவிர்க்கப்பட்டுள்ளன.
- [ ] பெரிய வினாக்கள் Quiz-ல் சேர்க்கப்படவில்லை.
- [ ] ஒவ்வொரு பதிவிலும் நான்கு தனித்தனி options, ஒரு correct answer, explanation மற்றும் Direct Source உள்ளன.
- [ ] `quiz.md`, `quiz.json`, Master Quiz அனைத்தும் ஒன்றுக்கொன்று பொருந்துகின்றன.

## இறுதி QA — Subject / Unit Complete Gate

ஒரு Unit-ஐ முடித்ததாகச் சொல்லும் முன் இவை அனைத்தையும் சரிபார்க்கவும்:

1. `answers.md` கேள்விகள் `questions.md`-ன் முழு வரிசையுடன் ஒப்பிடப்பட்டுள்ளன.
2. STEP 1, STEP 2, STEP 3 மூன்றும் தனித்தனியாக முடிக்கப்பட்டுள்ளன.
3. `quiz.md` மற்றும் `quiz.json` கேள்விகள், options, answer, explanation, source ஆகியவற்றில் ஒன்றாக உள்ளன.
4. JSON parse ஆகிறது; duplicate IDs இல்லை; ஒவ்வொரு item-லும் நான்கு unique options மற்றும் 0–3 வரம்பிலான correct index உள்ளது.
5. Master Quiz-ல் unit JSON-களின் கூட்டுத்தொகையைத் தாண்டி missing / extra / duplicate பதிவுகள் இல்லை; order பொருந்துகிறது.
6. ஆதாரமின்றி எந்த விடையும் `VERIFIED` என்று குறிக்கப்படவில்லை.
7. வெளியிடப்படாத / படம் இல்லாத / unresolved பதிவுகள் மற்றும் அவற்றின் காரணம் தெளிவாகக் குறிப்பிடப்பட்டுள்ளன.

### கட்டாய அறிக்கை வடிவம்
ஒவ்வொரு Unit முடிவிலும்:
- STEP 1: DONE / BLOCKED + கேள்வி எண்ணிக்கை
- STEP 2: DONE / BLOCKED + Original MCQ எண்ணிக்கை
- STEP 3: DONE / BLOCKED + Transformed MCQ எண்ணிக்கை
- Excluded: image-dependent / long-answer / unresolved எண்ணிக்கை மற்றும் காரணம்
- QA: answers order / markdown-json sync / JSON validation / master sync நிலை
- Remaining: மீதமுள்ள பணி அல்லது blocker

**மூன்று Steps-ல் ஏதேனும் ஒன்று BLOCKED என்றால் அந்த Unit COMPLETE என்று அறிவிக்கக்கூடாது. எல்லா Units-லும் மூன்று Steps முடிந்த பிறகே Subject COMPLETE என்று அறிவிக்க வேண்டும்.**

## Class / Subject / Term வேறுபாடுகள்

- இந்த Step 1–3 செயல்முறை எல்லா Class 1–12-க்கும் ஒன்றே.
- Lesson எண்ணிக்கை, Book Edition, Term / Annual structure, கேள்வி வடிவங்கள் மட்டும் மாறலாம்.
- ஒவ்வொரு repository-யிலும் ஏற்கெனவே உள்ள folder / filename convention-ஐப் பின்பற்றவும்; புதிய பெயர்களை ஊகித்து உருவாக்க வேண்டாம்.
- இந்த ஆவணம் பொதுவான workflow-ஐ நிர்ணயிக்கிறது; class-specific evidence அல்லது blueprint அல்லாத ஆவணத்தில் விதிகளை மாற்ற வேண்டாம்.
