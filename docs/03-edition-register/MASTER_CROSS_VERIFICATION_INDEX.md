## How to use this document

1. Open the required class section.
2. Click the direct **Page 2** link to inspect the book's imprint page.
3. Click the **official PDF** link to open the government source.
4. Follow the immutable GitHub commit link to inspect the exact page set and page map.
5. Read the audit status and decision notes before deciding whether to keep, promote or archive the book.

## Important decision guardrails

- Page-2 imprint is one important proof, not the sole edition decision.
- A matching imprint or page count does not prove that all content, TOC boundaries, exercises and Book-back questions match.
- Where the audit says `PENDING`, `MANUAL_REVIEW_REQUIRED`, `FULL_DIFF_PENDING`, `API_MAPPING_UNRESOLVED`, or `MAIN_CONTENT_COMPARISON_PENDING`, do not mark CURRENT or ARCHIVE.
- Do not replace main book/page assets or change viewer routing until official school distribution, full-book comparison, page maps, TOC and Book-back alignment are verified.
- Original audit branches remain preserved; copied evidence in main/Common is not permission to delete a branch.
- Archive only after the [Common Archive Policy](../04-quality-control/ARCHIVE_POLICY.md) has been satisfied.

### Source and link conventions for the registers

- Official listing: [SCERT textbook listing](https://tnschools.gov.in/scert-textbook).
- Distribution evidence: [Tamil Nadu Textbook Corporation notices](https://www.textbookcorp.in/schools).
- Full official PDF: link the exact URL stored in the book's source record.
- Official PDF Page-2 viewer: append `#page=2` to the exact PDF URL; this is only a viewer navigation hint until HTTP Range behaviour is proven.
- GitHub Page 2: link directly to the actual one-page PDF using an immutable Main commit SHA.
- GitHub page map: link to the matching `pages.json` at that same commit.
- Do not mark a book `CURRENT` from the academic year, filename, Page-2 imprint or page count alone. Keep unresolved cases `PENDING`.

The Textbook Corporation notice currently reviewed states that 2026–27 Term-II sales for Classes 1–7 began on 22-09-2026, Term-I sales for Classes 1–3 began on 25-05-2026, and Term-I for Classes 4–7 plus annual Classes 8 and 11 began on 14-05-2026. A sales notice confirms the release schedule; it does not by itself prove that the matching PDF URL is currently accessible.

**Current documentation rule:** Use the class-specific registers linked in Quick Navigation as the live per-book reference for current Main Page-2 URLs, official PDF links and edition status. The older detailed audit sections below are retained as dated comparison evidence; where their Main commit or promotion status differs, the current class-specific register and the 2026-11-09 Main snapshot above take precedence.
