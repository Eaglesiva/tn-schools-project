## How to use the links

- **Official Page 2:** exact official PDF URL with `#page=2`; opens the PDF viewer at page 2. It is not a separate one-page download.
- **Full PDF:** exact URL saved in the book's Main `edition.json`.
- **Main Page 2:** one-page PDF stored under the current immutable Main commit.
- **pages.json:** page order map for that same edition.
- **Official master SHA-256:** source hash recorded in the current Main `edition.json`.

## Verification boundary

The printed edition year is not the same as academic distribution year 2026–27. The link and Page-2 imprint records here are taken from current Main metadata; this documentation update did not perform a fresh official API/CDN download or a visual screenshot review of the binary PDFs. Recheck any OCR-noisy imprint through the direct Page-2 links before treating the exact text as visually verified.
