## How to read these links

- **Official PDF, Page 2:** opens the official full PDF with the viewer directed to page 2 using `#page=2`.
- **Full PDF download:** exact official SCERT/CDN PDF URL saved in the Main `edition.json`.
- **GitHub Page 2:** the separate one-page Page-2 PDF stored in the current Main commit.
- **pages.json:** ordered map of every page in the book.
- **Official listing:** the government SCERT listing page from which the exact book record should be identified.
