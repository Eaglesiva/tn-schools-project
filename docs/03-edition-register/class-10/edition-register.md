## Decision notes

- **Tamil:** the audit records an exact official master SHA-256/MD5 match with the existing main book. Keep the existing Tamil book; no replacement is required.
- **English and Mathematics:** official download metadata exists, but the audit explicitly records `MANUAL_REVIEW_REQUIRED` / `NOT_CHECKED`. Do not label these current or archive yet.
- **Science and Social Science:** official split page sets exist on `scert/class-10/official-version-updates`; manifest/page-file sequence is stored, but comparison with main content is still pending.
- The Class 10 Tamil 2024 (9-Iyal) vs 2025 (7-Iyal) diff report is linked from the [class-specific audit folder](https://github.com/Eaglesiva/tn-class-10/tree/main/docs/edition-audit/2026-27/).
- Page-2 imprint text above is taken from the audit manifest. Direct Page-2 links are provided for manual visual review. No final 2026–27 production switch is approved by this register.


## Current decision (Main versus update branch)

- **Tamil:** official master SHA-256 match is recorded; keep the existing Main pages.
- **Mathematics TM and EM:** previous audit records the Main copy as a 2025 printed edition, newer than the 2024 official portal copy. Preserve the existing Main copy unless a newer official source is found.
- **English:** still `MANUAL_REVIEW_REQUIRED`; no verified official-to-Main content match is recorded.
- **Science TM/EM and Social Science TM/EM:** official 2026–27 split sets exist on `scert/class-10/official-version-updates`, but their comparison with Main remains pending. They are not promoted to Main in the current tree snapshot. Do not call these four current Main editions yet.

The official 2026–27 annual sale notice includes Class 10, but that alone does not establish that all eight Main book folders are the latest content. The register preserves the above evidence-based statuses. No book PDFs were changed by this documentation update.
