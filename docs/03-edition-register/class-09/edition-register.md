## Decision and limitations

- The audit confirms all eight core books have matching Page-2 imprints and page counts against the official SCERT 2024 reprint. The full page-by-page content diff across all 2,504 pages remains pending; do not describe this as 100% content-identical.
- The audit excludes minority-language readers and supplementary teacher resources from the core Tamil/English register.
- Direct Page-2 links point to the actual split PDFs on `main`. The imprint and full-book comparison values are copied from the class audit record; the current task still requires visual Page-2 review and a current distribution check before a final 2026–27 CURRENT label.
- No book/page content was replaced.
