## How to use the links

- **Official Page 2:** exact official PDF URL with `#page=2`; opens the PDF viewer at page 2. It is not a separate one-page download.
- **Full PDF:** exact URL saved in the book's Main `edition.json`.
- **Main Page 2:** one-page PDF stored under the current immutable Main commit.
- **pages.json:** page order map for that same edition.
- **Official master SHA-256:** source hash recorded in the current Main `edition.json`.
