### 6.1 இந்த Byte Match எதை நிரூபிக்கிறது?

இந்த அறிக்கையில் உள்ள 57,588,385 bytes + MD5 / ETag match **Class 10 Tamil PDF-க்கானது மட்டுமே**.

இது நிரூபிப்பவை:
1. TNSchools / SCERT official application பயன்படுத்தும் API-யில் 10th_Tamil_Text.pdf என்ற PDF URL வழங்கப்பட்டுள்ளது.
2. அந்த official CDN URL-ல் இருந்து பெறப்பட்டதாக Antigravity பதிவு செய்த File Size / ETag மற்றும் Local Class_10_Tamil_Full_Book.pdf File Size / MD5 பொருந்துகின்றன.
3. இதனால் Local 248-page / 9-Iyal Tamil PDF, அரசு SCERT Portal-ல் தற்போது வழங்கப்பட்ட அந்த PDF-க்கு byte-identical என்று வலுவாக நிரூபிக்கப்படுகிறது.

இது **மற்ற 1–12 வகுப்புகளின் ஒவ்வொரு PDF-க்கும் Hash Match செய்யப்பட்டுவிட்டது** என்று பொருள் அல்ல. API-யில் 1–12 புத்தகப் பதிவுகள் இருக்கின்றன என்பதும், அந்தப் பதிவுகளில் வரும் ஒவ்வொரு கோப்பும் Local PDF-உடன் Match ஆகிவிட்டது என்பதும் வேறு வேறு.

அதேபோல் PDF File Match என்பது questions.md-ல் உள்ள 59 கோப்புகளின் ஒவ்வொரு கேள்வியும் சரியாக Extract செய்யப்பட்டது என்று தானாக நிரூபிக்காது. அது Question-level PDF Cross-check-க்கு ஆதாரமாகும்; தனி QA இன்னும் தேவை.

### 6.2 MD5 / ETag விளக்கம்

இந்த Report-ல் 32-character ETag மற்றும் Local MD5 ஒரே மதிப்பாக உள்ளன. சாதாரண single-part S3/CloudFront object-களில் ETag MD5 ஆக அமையலாம்; ஆனால் எல்லா S3 ETag-களும் எப்போதும் MD5 அல்ல (எ.கா. multipart uploads / encryption சூழல்கள்).

அதனால் அடுத்த முழு Audit-ல்:
- Government PDF-ஐ Download செய்த நேரடி File-க்கு SHA-256 கணக்கிட வேண்டும்.
- Local PDF-க்கும் SHA-256 கணக்கிட வேண்டும்.
- SHA-256 இரண்டும் பொருந்தினால் OFFICIAL_API_SHA256_MATCH என பதிவு செய்ய வேண்டும்.
- Remote SHA-256 பெற முடியாவிட்டால் Byte Size + ETag / MD5 ஆதாரத்தைத் தனியாகப் பதிவு செய்து MD5_ETAG_MATCH என்று குறிப்பிட வேண்டும்.

### 6.4 1–12 Full Government API Audit இன்னும் செய்ய வேண்டியது

இந்த Proof Report-ல் Class 10 Tamil மட்டுமே byte-for-byte match செய்யப்பட்டதாகக் கூறப்பட்டுள்ளது. பிற வகுப்புகள் / பாடங்களுக்கு "Government API-யில் உள்ளது" என்று மட்டும் பார்த்து Local PDF சரியானது என்று முடிவு செய்யக்கூடாது.

அடுத்த Audit-ல் ஒவ்வொரு Local PDF-க்கும்:
- Official API entry ID / Class / Subject / Medium / Term
- Official CDN URL
- Remote byte size
- Remote SHA-256 (அல்லது ETag / MD5, limitation உடன்)
- Local path / byte size / SHA-256
- Match / Mismatch / Not in API
- PDF page count
- Imprint / Contents / current distribution check
எனப் பதிவு செய்ய வேண்டும்.

இறுதி status-கள்:
- OFFICIAL_API_SHA256_MATCH
- OFFICIAL_API_MD5_ETAG_MATCH
- OFFICIAL_API_LISTED_LOCAL_MISMATCH
- OFFICIAL_API_LISTED_LOCAL_MISSING
- LOCAL_NOT_FOUND_IN_CURRENT_API
- API_ENTRY_NOT_UNDERSTOOD
- CURRENT_SCHOOL_USE_UNVERIFIED

**கடுமையான விதி:** Class 10 Tamil-ன் exact match-ஐ எல்லா புத்தகங்களுக்கும் பொதுமைப்படுத்தக்கூடாது. 1–12 முழு Audit முடிந்த பிறகே ஒவ்வொரு Subject / Medium / Term-ன் நிலையைச் சொல்ல வேண்டும்.
