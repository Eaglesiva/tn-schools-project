## Page-2 verification state

- Class 1–8 manifests include extracted Page-2 imprint text and split-validation data for candidate books.
- Class 9's manifest records Page-2 imprint and 100% page-content match against the current `main` page sets.
- Classes 10–12 have additional official-version manifests and reports; their individual book records still require consolidation into the same register schema.
- A direct GitHub link to a Page-2 split PDF is the preferred one-click proof. The text extracted into a manifest is supporting evidence, not a substitute for visually reviewing that PDF.
- Do not mark a book CURRENT or ARCHIVE solely from Page-2 imprint or equal page count. Check the official distribution record, whole-book comparison, TOC, page map, Book-back alignment and viewer routing.
