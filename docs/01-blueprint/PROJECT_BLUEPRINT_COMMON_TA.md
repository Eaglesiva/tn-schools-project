# Book Back Question, One-mark Answer & Quiz — Common Project Blueprint

> **பயன்பாடு:** Class 1–12; Tamil / English மற்றும் பிற பாடங்கள்; Tamil Medium / English Medium; Term-based / Annual books.
> **நிலை:** User-approved common workflow — 05-11-2026.

## 1. நோக்கம்

அனைத்து வகுப்புகளிலும் Book Back கேள்விகளை ஒரே அடிப்படை முறையில் சரிபார்த்து, ஒரு மதிப்பெண் / ஒருசொல் / Objective வினாக்களுக்கு மட்டும் விடை கண்டறிந்து, தகுதியானவற்றை நான்கு Options கொண்ட Quiz-ஆக அமைப்பது. பெரிய விடைகளை எழுதுவது இந்த workflow-இன் scope அல்ல.

## 2. முதன்மை ஆதாரங்கள்

1. ஏற்கெனவே உள்ள `questions.md` — அசல் கேள்வி, வரிசை மற்றும் பிரிவுகளுக்கான தொடக்க ஆதாரம்.
2. அந்த வகுப்பு / பாடம் / மொழி / term-க்கு பொருந்தும் தற்போதைய பாடநூல் PDF — கேள்வி wording, பாடப்பொருள், options மற்றும் விளக்கத்தைச் சரிபார்க்கும் முதன்மை ஆதாரம்.
3. நேரடி Answer Website அல்லது Guide PDF — குறிப்பாக One-mark விடையை உறுதிப்படுத்த உதவும் Answer Key ஆதாரம்.

Search preview அல்லது Homepage மட்டும் பார்த்து விடை உறுதியானது என்று கூறக்கூடாது. கேள்வி மற்றும் அதன் பதில் உள்ள நேரடி பக்கத்தைத் திறந்து சரிபார்க்க வேண்டும்.

## 3. ஒவ்வொரு Chapter-க்கும் நடைமுறை

1. Repository-யில் உள்ள subject / term / lesson folder அமைப்பை முதலில் படிக்கவும்; பெயர்களை ஊகித்து உருவாக்க வேண்டாம்.
2. அந்தப் பாடத்திற்கான `questions.md`-ஐப் படித்து, அதில் உள்ள கேள்விகளை தற்போதைய பாடநூல் PDF-உடன் ஒப்பிடவும்.
3. One-mark / One-word / Objective / நேரடி MCQ கேள்விகளை மட்டும் Quiz Candidate-ஆக வகைப்படுத்தவும்.
4. ஒவ்வொரு Candidate-க்கும் அதே கேள்வி மற்றும் context உள்ள ஒரு பொருத்தமான Direct Answer Source-ஐத் திறக்கவும்.
5. Answer-ஐ பாடநூல் context-உடன் ஒப்பிட்டு உறுதிப்படுத்தவும். Missing / ambiguous / conflicting answer இருந்தால் மட்டுமே இரண்டாவது Source தேடவும்.
6. உறுதியான விடை கொண்ட One-mark கேள்வியை நான்கு Options கொண்ட MCQ-ஆக அமைக்கவும்; அசல் கேள்வியின் பொருள் மாறக்கூடாது.
7. Chapter-ன் `quiz.md` மற்றும் `quiz.json`-ஐ ஒரே Data-விலிருந்து உருவாக்க / புதுப்பிக்கவும்.
8. `answers.md`-ல் One-mark / Objective விடை, சுருக்கமான காரணம், நேரடி Source URL மற்றும் தேவையான PDF page-ஐப் பதிவு செய்யவும்.
9. Subject-level Master Quiz ஏற்கெனவே உள்ளதா பாருங்கள்; இருந்தால் Unit JSON-ஐ அதில் sync செய்யவும். இல்லாவிட்டால் repository-யின் ஏற்கெனவே உள்ள convention-ஐப் பின்பற்றி ஒரே subject-level Master Quiz உருவாக்கவும்.
10. Chapter QA முடிந்ததும் அடுத்த Chapter-க்கு செல்லவும். Subject முடிந்ததும் மொத்த QA முடித்து அடுத்த Subject / Class-க்கு நகரவும்.

## 4. Quiz-ல் சேர்க்க வேண்டியவை

- பாடநூலில் ஏற்கெனவே உள்ள Objective / Multiple Choice கேள்விகள்.
- ஒருமதிப்பெண் / ஒருசொல் / குறுகிய விடை கேள்விகள் — சரியான விடை ஆதாரத்துடன் உறுதியானால் அவற்றை நான்கு-option MCQ-ஆக மாற்றலாம்.
- ஒரே ஒரு சரியான விடையைத் தெளிவாக நிரூபிக்கக்கூடிய கேள்விகள் மட்டுமே.

## 5. Quiz-ல் சேர்க்கக்கூடாதவை

- குறுவினா, சிறுவினா, நெடுவினா, விரிவான விளக்கவுரை, கட்டுரை.
- வீட்டுப்பாடம், திறந்தநிலை எழுத்துப் பணி, படைப்பாற்றல் பதில் கேள்விகள்.
- விடை உறுதியாகத் தெரியாத அல்லது இரண்டு Options சரியாக இருக்கக்கூடிய கேள்விகள்.

பெரிய விடை வினாக்களை MCQ-ஆக மாற்றக்கூடாது.

## 6. நான்கு Options அமைக்கும் விதி

1. ஒவ்வொரு Quiz வினாவிலும் துல்லியமாக நான்கு Options இருக்க வேண்டும்.
2. ஒரே ஒரு Correct Answer மட்டுமே இருக்க வேண்டும்.
3. மூன்று Distractors பொருத்தமானதாகவும் தவறானதாகவும் இருக்க வேண்டும்; ஆதாரமில்லாத Distractors உருவாக்க வேண்டாம்.
4. கேள்வியின் அசல் பொருள், பெயர்கள், எண்கள், காலம், அலகு, வினா நோக்கம் ஆகியவை மாறக்கூடாது.
5. Options வரிசையை மாற்றினால் `correctOptionIndex`-ஐ அதற்கேற்ப மாற்றி சரிபார்க்கவும்.
6. Answer அல்லது Distractors ஆதாரத்துடன் அமைக்க முடியாவிட்டால் Quiz-ல் publish செய்யாமல் `REVIEW_REQUIRED` எனக் குறிக்கவும்.

## 7. answers.md — என்ன எழுத வேண்டும் / என்ன எழுதக்கூடாது

**One-mark / Objective வினாக்கள்:**
- சரியான விடை.
- ஒரு சுருக்கமான காரண விளக்கம்.
- நேரடி Answer Source URL.
- பயன்படுத்திய பாடநூல் / Guide PDF page reference, தேவைப்பட்டால்.
- தெளிவான Verification Status.

**குறு / சிறு / நெடு / பெரிய விடை வினாக்கள்:**
- ஏற்கெனவே உள்ள blank placeholders-ஐ அப்படியே வைத்திருக்கவும்.
- ஏற்கெனவே உள்ள Answer Source links-ஐ அப்படியே பாதுகாக்கவும்.
- அந்த விடைகளை இப்போது எழுத வேண்டாம்.
- புதிய நீண்ட பதில்களை உருவாக்கவோ, வேறு Guide-களிலிருந்து நகலெடுக்கவோ, கூடுதல் Source hunt செய்யவோ வேண்டாம்.
- பயனர் தனியாகக் கேட்டால் மட்டுமே இந்த scope-ஐ மாற்றவும்.

## 8. Source மற்றும் Conflict விதிகள்

- One-mark Answer-க்கு ஒரு நல்ல Direct Source + பாடநூல் context போதுமானது.
- Answer கிடைக்காவிட்டால் `ANSWER_NOT_FOUND` அல்லது `REVIEW_REQUIRED` என்று உண்மையாகக் குறிக்கவும்.
- இரண்டு ஆதாரங்கள் மாறினால் மட்டுமே இரண்டாவது / கூடுதல் Source தேடவும்.
- அட்டவணை அல்லது வகைப்பாட்டை வாசிக்கும்போது தலைப்பு, row, column, அடுத்தடுத்த தலைப்புகள், முழுப் பக்க context அனைத்தையும் வாசிக்கவும்.
- தலைப்பைத் தவறாக இணைத்து conflict உருவாக்க வேண்டாம்.
- Third-party Website / mirror-ஐ Government / SCERT official source என்று குறிப்பிட வேண்டாம்.

## 9. கோப்புகள் மற்றும் Master Quiz

பாடம் / Term folder-ல் repository ஏற்கெனவே பயன்படுத்தும் இடத்திலேயே இக்கோப்புகளைப் பயன்படுத்தவும்:

- `questions.md` — Original Book Back Questions.
- `answers.md` — One-mark answers + evidence; மற்ற வினாக்களுக்கு existing placeholders / links.
- `quiz.md` — மாணவருக்கான வாசிக்க எளிய Quiz.
- `quiz.json` — `quiz.md`-க்கு பொருந்தும் structured data.

Subject-level Master Quiz உருவாக்கப்படும் இடம் அந்த repository-யின் உள்ளமைப்பைப் பின்பற்ற வேண்டும். பொதுவாக `<subject-or-term>/book_back_questions/quiz.json` போன்ற பாதை பயன்படுத்தலாம்; ஏற்கெனவே உள்ள வேறு convention இருந்தால் அதைத் தொடரவும்.

Question ID நிலையானதாக இருக்க வேண்டும். ஏற்கெனவே உள்ள ID-ஐ மாற்ற வேண்டாம். புதிய ID-களில் Class, Subject, Unit, Question ஆகியவை தெளிவாக அடையாளம் காணப்பட வேண்டும்.

## 10. இறுதி QA — ஒவ்வொரு Chapter / Subject முடிவிலும்

- கேள்வி wording மற்றும் வரிசை பாடநூலுடன் பொருந்துகிறதா?
- Quiz-ல் தகுதியான Objective / One-mark வினாக்கள் மட்டும்தானா?
- ஒவ்வொரு வினாவுக்கும் துல்லியமாக நான்கு Options உள்ளனவா?
- ஒரு சரியான விடை மட்டும்தானா?
- ஒவ்வொரு விடைக்கும் திறந்து சரிபார்த்த Direct Source உள்ளதா?
- `quiz.md` மற்றும் `quiz.json` உள்ள கேள்வி / Options / Answer / Explanation ஒன்றாக உள்ளனவா?
- JSON parse ஆகிறதா?
- Unit IDs duplicate இல்லையா?
- Master Quiz-ல் missing / extra / duplicate IDs இல்லையா?
- Master Quiz-ன் order, Unit JSON-களின் flatten செய்யப்பட்ட வரிசையுடன் பொருந்துகிறதா?
- `correctOptionIndex` எல்லா பதிவுகளிலும் 0–3 வரம்பிற்குள் உள்ளதா?
- பெரிய விடைகளுக்கான placeholders மற்றும் links மாற்றமின்றி உள்ளனவா?

## 11. அடுத்த Subject / Class-க்கு செல்லும் விதி

ஒரு Subject அல்லது Class-ஐ முடித்ததாகக் கூறுவதற்கு முன் அதன் கேள்வி எண்ணிக்கை, Quiz பதிவுகள், ஆதார நிலை, Master Quiz மற்றும் நிலுவைப் பணிகளைச் சுருக்கமாக QA செய்யவும். அடுத்த Subject / Class-க்கு செல்லும்போது அதன் சொந்த Book Edition / Medium / Term / Lesson structure-ஐத் தனியாகச் சரிபார்க்கவும்.

**முக்கியம்:** இந்த workflow Class 1–12 அனைத்திற்கும் பொதுவானது. புத்தகத்தின் அமைப்பு, term, பாடப்பிரிவு, lesson எண்ணிக்கை மட்டும் வகுப்புக்கு வகுப்பு மாறும்; workflow மாறாது.
